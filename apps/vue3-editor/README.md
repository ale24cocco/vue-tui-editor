# @toast-ui/tui-editor-vue3

Vue 3 wrapper for TOAST UI Editor.

## Install (workspace)
This package is intended to be used inside the tui.editor monorepo.

## Usage

Import CSS in your app entry (NOT in the library):

```ts
import '@toast-ui/editor/dist/toastui-editor.css'
import '@toast-ui/editor/dist/toastui-editor-viewer.css'
